# Naruto: Ascensão Shinobi

Protótipo de RPG 2D em pixel art. A versão mais recente é a **0.2.2**, com uma cena jogável na Rua da Academia.

## Jogar e desenvolver

Baixe ou clone este repositório e abra `naruto_ascensao_v0.2.2.html` no navegador. O HTML contém o código e os recursos da versão jogável. Para editar, abra o arquivo em um editor de código e recarregue a página depois de salvar.

Use **WASD** ou as **setas** para andar, **E** para interagir e **Esc** para abrir o menu. Em telas de toque, use os controles do jogo.
