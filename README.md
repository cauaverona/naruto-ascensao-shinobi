# Naruto: Ascensão Shinobi

RPG 2D em pixel art, jogo de fã sem fins lucrativos. A versão mais recente é a **0.3.0**: a Era da Academia completa, da matrícula ao exame de graduação.

## Jogar

Abra `naruto_ascensao_v0.3.0.html` no navegador. O arquivo contém o jogo inteiro e funciona offline.

Controles:

- **Andar:** WASD ou setas.
- **Interagir e avançar:** E, Enter ou espaço.
- **Menu:** Esc.
- **Celular:** direcional e botão A na tela.

## Desenvolver

O código fica em [game/](game/). Ali dentro:

1. Rode `npm install`.
2. Use `npm run dev` para o servidor local, `npm test` para os testes e `npm run build` para gerar o HTML final.

O andamento, os testes e a arquitetura estão em [STATUS.md](STATUS.md).
