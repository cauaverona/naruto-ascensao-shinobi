# Naruto: Ascensão Shinobi

RPG 2D em pixel art, jogo de fã sem fins lucrativos. A **v0.4.2** vai da matrícula até quatro missões de rank D da equipe Genin e a apresentação da escolta de Tazuna.

## Jogar

Abra `naruto_ascensao_v0.4.2.html` no navegador. O arquivo contém o jogo inteiro e funciona offline. Para apagar uma campanha, vá à lista de jornadas, use **Excluir save** no slot desejado e confirme.

Controles:

- **Andar:** WASD ou setas.
- **Interagir e avançar:** E, Enter ou espaço.
- **Menu:** Esc.
- **Celular:** direcional e botão A na tela.

## Desenvolver

O código fica em [game/](game/). Ali dentro:

1. Rode `npm install`.
2. Use `npm run dev` para o servidor local, `npm test` para os testes e `npm run build` para gerar o HTML final.

O andamento, os testes e a arquitetura estão em [STATUS.md](STATUS.md).
